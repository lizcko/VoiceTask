# VoiceTask 2.0

Обновление существующего приложения на React, TypeScript, Vite и CSS. Чат команд остаётся слева, календарь — справа. Данные хранятся в браузере. Сервер, авторизация, платные AI API и синхронизация не используются.

## Локальный запуск

Нужен Node.js 22. В корне проекта:

```powershell
npm ci
npm run dev
```

Адрес: http://localhost:5173/VoiceTask/.

В этой рабочей папке Node.js также установлен в `.tools`. Точная команда для текущего окружения PowerShell:

```powershell
$env:PATH = "$PWD\.tools\node-v22.14.0-win-x64;$env:PATH"; npm.cmd run dev
```

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

Сборка находится в `dist`. Предпросмотр: http://localhost:4173/VoiceTask/.

## Возможности

- Заголовок в верхней панели, поиск рядом с созданием записи, выпадающие фильтр и режим календаря.
- День, неделя, месяц, сетка из 12 месяцев; навигация по периодам и кнопка «Сегодня».
- Глобальный поиск по названию и комментарию, включая старое поле `description`. Задержка 180 мс, регистр не учитывается. Стрелки выбирают результат, Enter открывает запись, Escape и клик снаружи закрывают список. Результат переводит календарь на дату начала.
- Карточки показывают время начала и окончания, тип, важность и выполнение задачи. Большой красный знак выделяет важные записи. Обычные карточки не имеют цветной полосы. Выполненная задача остаётся на месте; выполнение можно отменить.
- Нажатие на дату открывает список записей дня с полными комментариями. Нажатие на запись заменяет список подробной карточкой, не создавая второго окна.
- Многострочный комментарий, готовые и произвольные цвета с предварительным просмотром, важность, выполнение. Поле в интерфейсе называется только «Комментарий».
- Окончание задаётся датой и временем либо часами и минутами продолжительности. Продолжительность показывается в подробной карточке. Минимум — 15 минут, максимум — 10 лет.
- В годовом режиме отображаются до трёх цветных точек и индикатор дополнительных событий. Точки учитывают фильтр и многодневные записи.
- Настройки сразу применяются и сохраняются. В меню ровно три раздела: «Внешний вид», «Календарь», «Уведомления».
- Профиль открывается через меню имени → «Мой профиль». Имя и аватар сохраняются. JPG/PNG до 5 МБ проверяются и уменьшаются до 256 пикселей; изображение можно удалить.
- История чата сохраняется. Подтверждение создания выдаётся только после успешной записи в localStorage.

На узких экранах временная и месячная сетки прокручиваются внутри календаря, сохраняя читаемую ширину колонок. Чат перемещается под календарь, как и в предыдущей адаптивной версии.

## Модель и совместимость данных

Основной ключ не изменён: `voicetask.entries.v1`.

Старые поля: `id`, `title`, `type`, `date` (`YYYY-MM-DD`), `time` (`HH:mm`), `duration` (число минут), `color` (`#RRGGBB`), `important`, `description`.

Дополнительные поля:

- `completed?: boolean` — выполнение задачи; отсутствие означает «не выполнено».
- `comment?: string` — необязательный совместимый комментарий. Чтение использует `comment ?? description`; редактирование комментария записывает оба поля согласованно.
- `startAt?: string`, `endAt?: string` — абсолютные моменты времени в ISO UTC для новых записей. Дата/время и продолжительность сохраняются также для совместимости.

Массовой перезаписи или миграции при запуске нет. Перед первым изменением существующего массива его исходная строка сохраняется в `voicetask.entries.backup.v1`. Запись выполняется до обновления интерфейса; ошибка сохранения не изображается как успех. Синтаксически повреждённое хранилище остаётся нетронутым, редактирование блокируется с сообщением. Неизвестные записи остаются в массиве без изменений; приложение сообщает об их количестве. Существующие пользовательские цвета и дополнительные поля сохраняются.

`localStorage.clear()` не используется. Демонстрационные данные не подставляются вместо данных пользователя. Изменение записей из другой вкладки обнаруживается перед сохранением: приложение обновляет список и просит повторить действие вместо перезаписи чужих изменений.

Сохранены прежние ключи имени и выходных: `voicetask.name`, `voicetask.weekend`.

Новые отдельные ключи: `voicetask.preferences.v2`, `voicetask.chat.v1`, `voicetask.avatar`, `voicetask.reminders.v2`. Последний содержит идентификаторы уже показанных напоминаний.

Данные привязаны к origin браузера. Локальный адрес и опубликованный GitHub Pages имеют разные localStorage; это обновление не переносит данные между ними. До ручной публикации полезно сохранить копию значения `voicetask.entries.v1` из DevTools опубликованного сайта.

## Многодневные записи и часовые пояса

Одна запись хранится один раз. Визуальные сегменты сохраняют её ID. Правка и удаление через любой сегмент меняют всю запись.

Интервал полуоткрытый: начало включено, конец исключён. Если запись заканчивается ровно в полночь, следующий день не получает пустого сегмента. Например, 12 октября 23:00 — 13 октября 02:00 даёт два сегмента: 23:00–24:00 и 00:00–02:00.

Новые записи используют выбранный IANA-часовой пояс и абсолютные ISO-моменты. Изменение пояса пересчитывает представление, сохраняя моменты. Старые записи без ISO-моментов остаются локальными: их дата и часы не изменяются молча; при редактировании показана соответствующая подпись.

Способ «Продолжительность» измеряет реально прошедшие минуты, в том числе при переходе на летнее время. Несуществующее местное время при переводе часов отклоняется. При повторяющемся осеннем часе выбирается одно детерминированное вхождение; выбор между двумя одинаковыми местными часами в форме пока отсутствует. Суточная сетка имеет 24 строки и не выделяет повторный час отдельной строкой: точные моменты и реальная продолжительность доступны в подробностях, запись остаётся доступна через список дня.

Если событие находится вне выбранного интервала часов, список дня и поиск по-прежнему дают доступ к нему. Длинный комментарий прокручивается внутри временного сегмента и не меняет временную сетку.

## Настройки

**Внешний вид:** светлая, тёмная или системная тема (реагирует на изменение системного предпочтения), основной цвет, три размера текста, стандартные/краткие/подробные карточки. Стандартный режим скрывает комментарий, краткий показывает одну строку с многоточием, подробный — весь текст с переносами.

**Календарь:** часовой пояс, режим следующего запуска, начало и окончание часов, три формата даты, цвета новых задач и встреч, подсветка сегодняшней даты, номера недель ISO, выходные. Цвета существующих записей не заменяются. Временное переключение режима календаря не перезаписывает режим по умолчанию.

**Уведомления:** включение, упреждение 5/15/30/60/1440 минут, задачи/встречи/важные записи, звук, всплывающие сообщения, ежедневный обзор. Важность — дополнительное основание для напоминания при отключённой категории.

## Ограничения уведомлений

Напоминания вычисляются каждые 15 секунд и после изменений. Они работают только при открытом сайте; фоновые вкладки могут проверяться реже из-за ограничений браузера. Разрешение на системные push-уведомления не запрашивается. Работа при закрытом браузере или выключенном компьютере не предусмотрена.

Колокольчик показывает только напоминания о записях. Создание, сохранение и удаление показываются отдельными краткими подтверждениями. Выполненные задачи и прошедшие встречи не напоминаются. Просроченная задача показывается один раз; факт показа сохраняется. При изменении начала получается новый идентификатор напоминания. Удаление/выполнение/перенос очищают неактуальные напоминания. Будущие напоминания остаются доступны в колокольчике в пределах выбранного окна упреждения, в том числе после перезагрузки.

Ежедневный обзор — сообщение о количестве записей текущего дня, один раз при первой проверке дня с включённой настройкой. Он не обещает доставку в определённый час. Звук — короткий сигнал Web Audio после взаимодействия с сайтом; браузер, устройство и режим без звука могут блокировать воспроизведение.

## Команды чата

```text
задача Подготовить отчёт; сегодня; 14:00
встреча Обсудить проект; завтра; 10:00; 90; важно
задача Работа на два дня; 2026-10-12; 23:00; 2880
встреча Поездка; 2026-12-31; 23:00; 2027-01-02 02:00
помощь
```

«Сегодня» и «завтра» учитывают выбранный часовой пояс. Сохранены существующие команды и объяснение ограничений для свободного текста. LLM и голосовое распознавание не подключены; прежняя кнопка микрофона сообщает об этом прямо.

### Дополнительный ручной чек-лист

1. На своём устройстве создайте задачу и встречу, отредактируйте и удалите их. Отметьте и снимите выполнение, проверьте сохранение после F5.
2. Введите название прошедшей и будущей записи, затем текст комментария. Выберите результат стрелками/Enter, проверьте дату и подробности. Закройте поиск Escape и кликом снаружи.
3. Создайте важную запись с произвольным цветом и длинным многострочным комментарием. Проверьте три режима подробности, особенно короткий временной сегмент и пересечение соседних записей.
4. Создайте 23:00–02:00, событие на 48 часов, через конец месяца и года, через 29 февраля. Во всех четырёх режимах проверьте сегменты/точки и единое удаление.
5. Уменьшите интервал отображаемых часов так, чтобы событие было вне сетки. Откройте его через заголовок дня и поиск.
6. Меняйте тему, основной цвет, размер текста, формат даты и часовой пояс. Перезагрузите страницу; режим по умолчанию должен примениться только при открытии. Проверьте в системной теме переключение темы ОС.
7. Загрузите настоящий JPG, PNG, слишком большой файл и повреждённое изображение. Убедитесь в корректных сообщениях, отображении и удалении аватара.
8. Создайте событие через 5 минут, включите напоминания за 5 минут. Оставьте сайт открытым, проверьте колокольчик, всплывающее сообщение и слышимость звука. Выполните задачу/перенесите срок и проверьте обновление колокольчика.
9. Создайте просроченную задачу: напоминание должно появиться один раз и не повторяться после F5. Включите обзор и проверьте его повторное появление на следующий день.
10. Откройте две вкладки, измените записи в первой, попробуйте сохранить во второй. Проверьте защиту от перезаписи. При заблокированном localStorage не должно появляться ложного подтверждения успеха в чате.
11. Проверьте браузеры Firefox/Safari и мобильное устройство: прокрутку сетки, фокус модальных окон, нативные дату/время и палитру.

Слышимость звука, физический выбор JPG/PNG через системный диалог, переход через реальные сутки и совместимость Firefox/Safari требуют ручной проверки на соответствующем устройстве.

## Доработка настроек по макетам

Настройки остаются модальным окном над затемнённым календарём. Внутри — тёмное боковое меню с тремя разделами и светлые карточки параметров. Тёмная и системная темы, индивидуальный акцент и сохранённые настройки поддерживаются без изменения ключей хранилища.

- Тема, размер текста, плотность карточек и режим следующего открытия выбираются карточками с нативными радиокнопками. Поддерживаются клавиатура и видимый фокус.
- Основной цвет выбирается из палитры или нативным выбором произвольного цвета. Выбранный цвет применяется сразу.
- Часовые пояса имеют подписи с GMT-смещением; начало и конец дня задаются списками часов. Недопустимые границы недоступны для выбора.
- Цвета типов и формат даты размещены рядом. Два нижних переключателя идут сразу под ними с отступом 13 px, без большого пустого блока.
- Уведомления оформлены переключателями с пояснениями; время напоминания выбирается из пяти вариантов. Логика существующих напоминаний сохранена.
- Профиль оформлен отдельным модальным окном с карточками изображения и имени. Он открывается только через меню пользователя.
- На мобильном экране разделы меню расположены сверху, карточки идут одной колонкой, содержимое окна прокручивается по вертикали. Горизонтального переполнения нет.

Первое, второе и третье вложения использованы как образцы настроек. Четвёртое повторяет уведомления и не содержит отдельного макета профиля; профиль оформлен в том же стиле по ранее согласованным полям.

Дополнительные проверки браузера включены в `tests/browser.test.mjs`: выбор темы стрелками, готовый и произвольный акцент, переключение подробности, сохранение настроек, интервал часов, приоритет индивидуального цвета и отсутствие большого отступа после цветов. Снимки трёх разделов и профиля сохранены локально в `.tools/settings-*.png` и `.tools/profile-*.png`. Визуальная проверка описана в `design-qa.md`.
